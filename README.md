## Sobre mim

Sou **desenvolvedor front-end e entusiasta de UI/UX**, estudante de **Ciência da Computação**. Crio aplicações web modernas com **React** e **TypeScript**, sempre com foco em **design centrado no usuário**: gosto de cuidar da experiência desde o protótipo no Figma até o deploy.

Também atendo como **freelancer**, entregando sites institucionais, landing pages e identidade visual para clientes de diferentes segmentos.

- 🎨 Perfil híbrido: **design de interface** + **código de produção**
- 🔎 Sites pensados para **SEO** e performance
- 🌱 Estudando continuamente TypeScript, React e o ecossistema .NET
- 🎯 Procurando vagas de dev
